Обновление и установка

Список перепроверяется GitHub Actions примерно раз в 6 часов. Можно установить эту панель как приложение: в Chrome нажми меню ⋮ → Установить приложение или Добавить на главный экран.

Важно. FreeWave не владеет серверами. Это публичные узлы третьих лиц: они могут отключиться, ограничивать трафик или собирать метаданные. Результаты измеряются на GitHub Actions, поэтому скорость на телефоне будет другой. Не используй такие узлы для чувствительных данных.
