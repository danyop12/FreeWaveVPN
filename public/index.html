Добавить подписку
3. Включить автоматический выбор узла

Создай группу Least Ping: Xray будет выбирать узел с наименьшей измеренной задержкой из импортированной подписки.

Как создать группу FreeWave Auto
  1. В v2rayNG нажми меню добавления профиля и выбери Add [Policy group].
  2. Название группы: FreeWave Auto.
  3. Тип группы: Least Ping.
  4. В поле From subscription group выбери только что импортированную подписку FreeWave.
  5. В поле Remarks regex filter введи .*, чтобы включить все узлы этой подписки.
  6. Сохрани группу. На главном экране выбери FreeWave Auto вместо отдельного сервера и подключись.

Least Ping ориентируется на задержку до тестового адреса, а не на гарантированную максимальную скорость загрузки. Новые соединения могут выбирать другой подходящий узел по обновлённым измерениям; это не гарантирует бесшовного переноса уже открытых соединений.

4. Включить автообновление и автозапуск

В v2rayNG включи автоматическое обновление подписок, интервал 360 минут и Connect after device boot. В Android VPN Settings включи Always-on VPN.

Настройки для Android и Infinix
  1. В настройках подписки включи Enable automatic update. В общих настройках включи Automatically update subscriptions и поставь 360 минут.
  2. В VPN Settings включи Connect after device boot.
  3. Открой системные настройки Android → VPN → v2rayNG → Always-on VPN. «Блокировать соединения без VPN» включай только после проверки, иначе при падении узла интернет может пропасть полностью.
  4. На Infinix разреши v2rayNG автозапуск и фоновую работу, а для батареи выбери «Без ограничений» / «Не оптимизировать». Названия пунктов зависят от версии XOS.

DNS-фильтрация рекламы

экспериментально

Можно попробовать AdGuard DNS для блокировки многих рекламных и отслеживающих доменов. Это не убирает рекламу гарантированно во всех приложениях и не является способом убрать рекламу в официальном YouTube.

Как попробовать через v2rayNG
  1. Сначала запомни текущие значения DNS в v2rayNG, чтобы можно было вернуть их обратно.
  2. Открой меню → Settings и найди VPN DNS. Укажи 94.140.14.14.
  3. Найди Remote DNS и укажи https://dns.adguard-dns.com/dns-query, если поле принимает HTTPS DNS-адрес.
  4. Сохрани настройки, отключи и снова подключи VPN. Проверь обычные сайты, приложения и загрузку видео.
  5. Если сайты перестали открываться, очисти эти значения или верни прежние DNS-настройки.

Это DNS-фильтрация, а не полноценный блокировщик рекламы. Она может убрать часть рекламы и трекеров, но реклама YouTube в официальном приложении обычно продолжит показываться. Для YouTube DNS-фильтрация не даёт надёжного результата.

Адреса взяты из публичных настроек AdGuard DNS. Подробнее: официальная инструкция AdGuard.

Проверка скорости на телефоне

локальный тест

Рейтинг FreeWave измеряется на GitHub Actions и не показывает скорость именно на твоём Infinix. Чтобы выбрать лучший сервер для себя, сравнивай реальные замеры на одном и том же телефоне и сети.

Как сравнить узлы правильно
  1. Оставь включённым тот же Wi-Fi или мобильный интернет.
  2. Открой Speedtest и сделай один замер с VPN выключенным. Запиши загрузку, отдачу и ping.
  3. В v2rayNG открой тест задержки для группы FreeWave Auto, затем подключись и повтори Speedtest.
  4. Для сравнения отдельных серверов временно выбирай их по одному, каждый раз повторяя тест в тех же условиях.
  5. Сделай по два-три замера и сравни средний результат. Не выбирай сервер только по минимальному ping: важны скорость загрузки и стабильность.

Не запускай много тестов одновременно: это расходует трафик и может перегружать публичные узлы. Результаты меняются в зависимости от времени, маршрута и нагрузки сервера.

Обновление и установка

GitHub Actions перепроверяет серверы примерно раз в 6 часов. Открытая панель сама обновляет опубликованные данные каждые 5 минут и при возвращении на вкладку. Это обновление не запускает внеплановое сканирование серверов. Можно установить эту панель как приложение: в Chrome нажми меню ⋮ → Установить приложение или Добавить на главный экран.

Уведомления браузера приходят, пока панель открыта или работает как приложение. Для push-уведомлений при полностью закрытом приложении нужен отдельный push-сервис.

Важно. FreeWave не владеет серверами. Это публичные узлы третьих лиц: они могут отключиться, ограничивать трафик или собирать метаданные. Репозиторий, панель и опубликованные подписки тоже открыты всем — личным этот VPN-сервер не становится. Результаты измеряются на GitHub Actions, поэтому скорость на телефоне будет другой. Не используй такие узлы для чувствительных данных.
